# Duck Empire — V1

نسخة أولية أصلية لـ Telegram Mini App، مستوحاة وظيفيًا من ألعاب إدارة/جمع البط، بدون استخدام شعارات أو أصول لعبة أخرى.

## الموجود في V1
- واجهة Mobile First
- Home / Farm
- Duck profile
- Feed + XP + Coins/Corn
- Egg Field 5×5 و7×7
- Smart Merge (واجهة أولية)
- Hatch (واجهة أولية)
- Duck inventory
- Market
- Tasks
- Breeding screen
- Telegram Mini App initialization
- تصميم RTL ومتجاوب

## التشغيل
يمكن نشر ملفات الواجهة على GitHub Pages أو أي استضافة static. Telegram Mini Apps يمكن تشغيلها مباشرة داخل Telegram عبر رابط التطبيق الرسمي. راجع توثيق Telegram Mini Apps.

## المرحلة التالية
Backend + PostgreSQL + Telegram user validation + inventory server authority + real merge/breeding + market + referrals + events + tournaments + admin panel + anti-cheat + TON.
